# 遥控器：转向控制版

原程序逻辑备份：../backup/remote.user-original.ino（整理格式和部分注释，未作为逐字文本备份）。

目标接收板 MAC：24:62:AB:F0:72:94；实际本机与 peer 信道均固定为 1。

GPIO32 接摇杆模拟输出，摇杆输出须限制在 ESP32 允许的 3.3V 范围；GPIO25/26 按钮保留输入配置，不参与控制。小船自动定速 580 RPM，发送的第一字段固定 100，仅维持原八字节协议；第二字段为 60～120 的角度。

保留 ADC 1750～2150 死区，死区两侧分段映射以避免跳变，端点假定 0/4095。实际摇杆中位和端点、左右方向与舵机物理摆幅需校准。

初始化逐步检查，失败禁发。约每 30ms 尝试发送，等待上一包发送回调，实际频率受回调耗时影响。十次 ADC 采样求平均，不使用按钮阻塞延时。回调只记录成功/失败计数，主循环每秒报告 ADC、角度、发送统计和本地错误。发送回调超时 500ms 禁止后续发送，需重启排查。delivered 仅表示 MAC 层发送成功，不等于已验证舵机实际动作。

## 审查与验证

检查收发协议均为两个 int32_t、共 8 字节，角度范围匹配已烧录的小船程序。发送等待标志在调用前置位；失败清除；回调共享变量由临界区保护。故障分支不发送。

直接包含 steering.h，以 g++ 运行全部 4096 个 ADC 输入的范围、单调性、边界连续性、死区和越界钳位检查，全部通过。

Arduino CLI 1.5.1，Arduino-ESP32 3.0.2，目标 ESP32 Dev Module，整体编译退出码 0，无警告。Flash 904145 字节（68%），全局 RAM 43748 字节（13%）。固件及源码快照在 ../firmware/remote-esp32-3.0.2-2462ABF07294。

未烧录遥控器，未验证实机摇杆、无线接收或舵机动作。发送回调签名按 3.0.2 编译验证，升级核心需重新核对接口。没有添加加密或接收端身份过滤。
