ESP32 小船 / 遥控器 保姆级烧录与换板配对包
================================================
适用：Windows 10/11、经典 ESP32-WROOM / ESP32-D0WD 开发板（不是 S3/C3）。
不需要 Codex、Arduino IDE 或安装 Python。两个固件都已编译通过。
本包脚本已检查语法，控制逻辑与 MAC 解析回归通过；本包新增配对流程尚未在实际板上验证。

一、先读这四条
1. 必须先“全部解压”，不能在 ZIP 里面直接双击。建议解压到 D:\ESP32Kit。
2. 刷写和配对前断开动力电池，尤其电机/舵机电源，只保留 USB 给开发板供电。
3. 小船程序上电自动启动到目标580RPM，不由遥控器油门控制；断开遥控只回中，不停动力。
4. 本包的01/02烧录会覆盖前4MB，包含原NVS配置；配对地址会重置，所以刷写后须重新配对。

二、认清三个入口
01_烧录小船.cmd   = 给小船主控烧录
02_烧录遥控器.cmd = 给遥控器烧录
03_换板配对.cmd         = 读取当前板身份，保存对方MAC（换板时使用）

首次使用：两块板都需要刷本包新版，旧版没有配对命令，不能直接运行03。

三、第一次烧录：一步一步
1. 用USB数据线连接“小船板”。不要同时插多块不明板子。
2. 双击01_烧录小船.cmd。它要求确认动力断开，输入“确认” 回车。
3. 窗口会显示串口，例如 COM8；输入该串口名回车。
   没有串口：换数据线/USB口；在设备管理器查看。CH340驱动官方页面：
   https://www.wch.cn/downloads/CH341SER_EXE.html
4. 窗口读取芯片MAC和Flash容量，再询问是否确实是小船板。核对后输入“确认”。
5. 等待完整原Flash备份，8MB可能需要约3～5分钟。期间不要拔线。
6. 自动写入并校验，出现 “固件烧录及写入校验成功” 即烧录成功。按任意键关窗口。
7. 拔下小船板，连接遥控器，双击02_烧录遥控器.cmd，重复上述步骤。
8. 不要把01和02选反；脚本显示role但不能自动知道你把板子装在哪里。

串口连接不上：关掉Arduino串口监视器等占用程序；按住BOOT再重试；连接开始后松开。
若备份失败，脚本不会继续写入。先修复数据线/串口问题，再重新运行。
运行被Windows SmartScreen拦截时，先核对来源和SHA256，不要盲目关闭系统防护。

四、一键换MAC / 换一块烧坏的板
不用手工改源码，也不用重新编译。
1. 新板先用对应01/02刷本包固件，旧的另一块也必须已经使用本包固件。
2. 连接“新换的那块板”，双击03_换板配对.cmd。
3. 输入“确认”确认动力断开，选择COM，脚本显示它的角色、自身MAC和将配对的对端MAC。
4. 再输入“确认”，脚本保存到板上NVS、重启并读回确认；出现 “当前板子的配对配置已保存” 才算成功。
5. 拔下新板，接上另一块板，再运行一次03_换板配对.cmd。
   此次会使用刚记录的新MAC更新另一端。两个板都配置好才完成。
6. pair-data.json自动记录两块板最新MAC；请将它与工具包一起保留，今后继续使用。

如果两块板一起换：先配置小船，再配置遥控器，最后再接小船运行一次03，共三次。
如果工具包被重新解压、pair-data.json丢失：同样按“小船→遥控器→小船”运行03三次即可重建。
如果显示“无法读取配对信息”：板上还是旧固件、角色刷错或串口不对；先检查再用01/02。
配对不会伪造/改写芯片出厂MAC，也不烧写eFuse；只是让双方记住新的对方地址。

五、验证
两块板都上电，摇动摇杆。串口115200可观察遥控delivered增长、小船rx增长和angle变化。
MAC层发送成功不等于舵机动作已验证。屏幕故障、舵机供电/接线、编码器参数需分别检查。
小船没接编码器时会锁定停机；连接好再断电重启。TS90A使用合适5V电源并共地。
屏幕模拟显示540～600，标记SIM RPM，不代表真实580RPM。真实测速在串口。

六、备份在哪里 / 刷错了怎么办
每次烧录自动在 备份与日志\日期时间-角色\ 保存 flash-before.bin、校验值与刷写日志。
flash-before.bin是当次完整Flash备份，别当作垃圾删除，也别和公开材料一起发出去。
如果刷错角色，先保留备份，再用正确01/02重刷，最后两端重新配对。
恢复原完整Flash备份需要确认它属于当前这块板：用随包esptool将其写入0x0。
不要拿别人的整片备份覆盖自己的板；不确定时先停下核对MAC。

七、只用图形工具的人
也可用乐鑫Flash Download Tools：ESP32 / Develop / UART；选择firmware里对应merged.bin，
地址0x0，COM选实际串口，勾选DoNotChgBin（如有），点击START。
官方说明：https://docs.espressif.com/projects/esp-test-tools/en/latest/esp32/production_stage/tools/flash_download_tool.html
用此方法不会自动备份，请先自行备份。配对仍用03_换板配对.cmd。

八、文件说明
firmware：两端合并固件与编译记录；tools：独立esptool及许可证；source：对应源码和回归测试。
checksums.json：固件和工具SHA256，脚本在操作前核对。备份与日志及pair-data.json在运行时生成。
本包默认原始配对：小船24:62:AB:F0:72:94，遥控器24:62:AB:EF:CF:84，信道1。
当前本机两块板仍是上一审查版；本包新版未替你烧录。

操作入口、提示和确认输入已中文化。芯片型号、MAC地址、串口名和底层诊断日志保留技术原文。
当前配对依赖本地记录，不会搜索或配置附近无线设备；保存成功仅代表当前USB板子，仍需双板通信验证。
