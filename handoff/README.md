# 保姆工具维护源码

当前推荐单入口向导：`wizard.ps1`，识别 `VERSION=2 STEER=20`，旧30°/无角度标记程序进入备份升级流程。

`start.ps1`、三个编号启动入口与原说明是此前三入口工具的维护材料；不作为当前单入口20°包的使用入口。

此目录仅维护脚本源码。实际交付包还需要独立 esptool、按对应角色编译的合并固件和 SHA256 清单。工具链、固件和ZIP未上传。不要直接在此目录运行并假定它已经具备全部配套文件。

向导分三步通过USB登记小船、登记遥控器、接回同一小船。无默认对端地址，不读取旧电脑MAC缓存，不无线搜索。配置保存与重启读回成功不等于实机无线/执行机构验证通过。

测试：`tests/wizard-tests.ps1` 为模拟流程检查，`tests/wizard20-parser.ps1` 验证新版/旧版身份标记识别；均不访问真实串口。完整实机流程待验证。
